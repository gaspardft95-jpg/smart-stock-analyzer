# 1 Smart Stock Analyzer

Une application web d'analyse boursière interactive et d'aide à la décision d'investissement, codée en Python avec **Streamlit**.

## 2 Fonctionnalités
* **Données en temps réel** : Récupération des cours et métriques via l'API Yahoo Finance (`yfinance`).
* **Analyse Fondamentale** : Visualisation de l'historique des résultats nets, EBITDA et PER.
* **Simulateur de Valeur Intrinsèque** : Estimation de la valeur réelle de l'action basée sur le modèle des flux de trésorerie actualisés (DCF) avec curseurs interactifs.
* **Graphiques Dynamiques** : Graphiques boursiers intéractifs propulsés par **Plotly**.

## 3 Stack Technique
* **Langage** : Python
* **Interface Web** : Streamlit
* **Analyse de données & Graphiques** : Pandas, Plotly, yfinance
